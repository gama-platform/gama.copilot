GitHub Copilot for GAMA

This is an Eclipse p2 update site. In GAMA, use the Copilot installation command; or add https://gama-platform.org/gama.copilot/ in Help > Install New Software....

Baseline: Eclipse 2026-03, Java 21 or newer. GitHub sign-in and a Copilot entitlement are required. Platform support: Linux GTK x86_64, Windows x86_64, and macOS x86_64 / Apple Silicon.

Source, dependencies, compatibility, licenses and issue routing. Upstream Copilot is unmodified; this is an independent GAMA integration, not a Microsoft or GitHub product.
